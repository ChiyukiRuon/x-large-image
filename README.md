# X Large Image

在 X（Twitter）多图帖子里添加一个「拼接下载」按钮。点击后，将原图按附件顺序从左到右无缝拼接，直接下载为 PNG。

## 安装

1. 打开 `chrome://extensions` 或 `edge://extensions`，开启「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本仓库根目录。
3. 刷新 X 页面，在多图帖子下点击「拼接下载」。

支持同一帖子中已加载的至少 2 张静态图片，按附件编号从左到右拼接，不缩放。下载前自动去掉内部接缝处检测到的窄纯色边条和浅色细线。高度不同时顶部对齐，底部留透明区域。

结果限制为 6400 万像素、单边 32767 像素，单张源文件不超过 40 MB。

## 验证

`npm test` 运行核心测试；`npm run test:browser` 使用本机 Chrome 和模拟图片验证按钮到 PNG 下载请求的流程。Windows PowerShell 可使用 `npm.cmd`。浏览器测试需要 Node.js 24。
